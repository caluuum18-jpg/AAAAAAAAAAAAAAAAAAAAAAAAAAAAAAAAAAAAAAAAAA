# Bench program

A standalone, iPhone-friendly bench calculator. No build tools or dependencies.

## Publish on GitHub Pages

1. Create a repository, or open the repository you want to use.
2. Upload **index.html** into the repository root and commit it. Upload the file itself, not the ZIP or its enclosing folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, your main branch, and **/ (root)**. Save.
5. Open the Pages link shown in Settings on your iPhone.
6. In Safari, tap **Share → Add to Home Screen**.

You can also open index.html directly on a computer to preview it. Use the hosted Safari link on iPhone.

## Use

- The accessory tracker near the top has independent Set 1 and Set 2 weight boxes for Dips, Incline DB, Rows, Lat Raise and Pushdowns. Each number saves automatically in kg; clear a box to remove it. It keeps only the latest weights, shared across weeks and program versions.
- Program version controls are at the bottom of the page.

- Enter your bench 1RM. Bench and Variation percentages show the calculated load alongside the percentage, rounded to the nearest 2.5 kg. Midpoint ties round up.
- Optional: enter a separate pulldown 1RM for the pulldown percentages. They never use your bench max.
- Select Week 1–4 to see its sessions in the supplied order.
- The PR single stays RPE 8–9.5, with its load chosen on the day.
- Accessory rows with no percentage remain unprescribed.
- **Edit program** changes week/day names, exercises, sets/reps, percentages, which max to use, and RPE/notes. Add or remove weeks, days or exercises. No coding required.
- **Save new version** creates Mod 1, Mod 2, etc. or a custom name, with the save date and time. The dropdown and **Version history** reopen any earlier save. Original program always stays available.
- **Export backup** downloads all saved versions, maxes and accessory weights. **Import backup** restores a collection after confirmation, replacing the current browser's collection. Export your current collection first if you need to keep it.
- Saves belong to that browser and website path. They do not automatically sync between devices or browsers. Clearing website data can remove them. Keep a backup.
- To change the default for new visitors without coding, choose a version, expand **Saving, sharing & iPhone**, and tap **Download selected version as page**. Replace the repository's index.html with that downloaded file. Existing visitors keep their local selection; new visitors get the chosen default. The original remains available.

## Program transcription

All four weeks follow the supplied program: same row order, percentages, set/rep prescriptions, accessory RIR targets, and day labels, including the unusual Week 3/4 numbering. The taper remains under Week 3.

The compressed Pushdowns2x8 entries are transcribed as Pushdowns 2×8 in Weeks 1–2. Week 4 uses the separately specified 1×8 deload prescription. Peaking stays 4–5×2 at 88%. No training modifications were made.

The page uses no external scripts, analytics, fonts or tracking. Internet is needed to load the hosted page; offline installation is not included.
